# Copy

The words Quz uses in its Swedish UI, so every screen says the same thing. Add to this list when a new term comes up.

| Concept | Swedish | Not |
|---|---|---|
| A round of the quiz | **omgång** (omgången, omgångar, omgångarna) | rond |
| The ordinary kind of round | **Frågeomgång** | Frågerond |
| The kind of a round | **Typ av omgång** | Sorts rond |
| The people answering, in explanatory texts | **deltagarna** | lagen |
| A team as a unit (team names, "Anmälda lag", scores) | **lag** | deltagare |
| A choice or item in multiple choice, sort and match | **alternativ** | sak, saker |
| Correctly spelled | **rättstavat** | rätt stavat |
| The two hosts, talked about | **domarna** (for example "Anteckningar för domarna", "Quz för domare") | värdarna, quizmastrarna |
| The two hosts, addressed directly | **ni** (for example "granskar ni") | |
| Sort question ends | **Högst upp betyder / Längst ner betyder**, placeholders "Störst" / "Minst" | Början / Slutet |
| Match question key | **Korrekta par** | Rätta par |

Messages say what to do, in a full sentence ending with a period: "Lägg till minst 2 alternativ att sortera."
