# Copy

The words Quz uses in its Swedish UI, so every screen says the same thing. Add to this list when a new term comes up.

| Concept | Swedish | Not |
|---|---|---|
| A round of the quiz | **omgång** (omgången, omgångar, omgångarna) | rond |
| The ordinary kind of round | **Frågeomgång** | Frågerond |
| The kind of a round | **Typ av omgång** | Sorts rond |
| The people answering, in explanatory texts | **deltagarna** | lagen |
| A team as a unit (team names, "Anmälda lag", scores) | **lag** | deltagare |
| A choice or item in multiple choice, sort and match | **alternativ** | sak, saker |
| Correctly spelled | **rättstavat** | rätt stavat |
| The two hosts, talked about | **domarna** (for example "Anteckningar för domarna", "Quz för domare") | värdarna, quizmastrarna |
| The two hosts, addressed directly | **ni** (for example "granskar ni") | |
| Sort question ends | **Högst upp betyder / Längst ner betyder**, placeholders "Störst" / "Minst" | Början / Slutet |
| Match question key | **Korrekta par** | Rätta par |
| The scores between rounds | **Topplista** ("Topplista efter omgång 2") | Ställning, poängtabell |
| Points | **12 p**, **2,5 p** | poäng after a number |
| The scores after the last round | **Slutresultat** | Sluttopplista |
| A team joining on its phone | **Gå med**, with **Lagets namn** and **Lagets färg** | Anmäl, registrera |
| The shared screen | **TV:n** ("Titta på TV:n.", "Öppna TV-vyn", "Visas på TV:n nu", "Nästa på TV:n") | skärmen, storbildsskärmen |
| A question's sound or video | **Klipp**, **Spela** / **Pausa**; on the TV **Ljudklipp**, **Videoklipp**, **Lyssna!** | Media, Spela upp (only in the editor) |
| The trip's clue in the admin | **Ledtråd 2 av 5 · 8 poäng · nästa om 0:12**, **sista ledtråden**, **Filmen är slut.** | |
| Answering on the phone | **Ert svar** (a typed answer), **Håll och dra för att flytta** (sort), **Lista A** / **Lista B**, **Tryck på ett alternativ och sedan på dess par**, **3 av 5 par** (match), **Ingrediens 1**, **5 ingredienser · ordningen spelar ingen roll**, **3 av 5 ifyllda**, **Tomma rader är okej.** (ingredients), **a) Artist** / **Delfråga a)**, **Ni kan lämna ett fält tomt.** (free text), **Skriv ett svar**, **Lägg till**, **7 svar**, **Det finns redan.**, **Listan är full med 100 svar.**, **Bara tillagda svar räknas.** (list), **Inget svar sparades.** (time out with no answer), **Välj ett alternativ**, **Skicka svar**, **Svaret låses när ni skickar det.**, **Svar skickat ✓** | Lämna in |
| The hosts' review list | **Granska svar**, **2 kvar** / **Allt granskat**, **Ogranskade svar ger 0 p.**, **Inga svar att granska.**, **3 lag**, **Rätt** / **Fel**, **Samma som…** (a list text as another item), **Rätt som…** (a long key); the TV's **Inga rätta svar ännu.**, **och 5 till**; the AI judge: **Låt AI bedöma nästan rätt svar** (editor), **AI:n bedömer svaren…**, **AI:n kunde inte bedöma svaren. Granska dem själva.**, the mark **AI** | Godkänn, Underkänn, KI |
| Who has answered | TV: **4 av 6 lag har svarat**; admin: **Svarat** / **Väntar** | |
| Answers refused by the server | **Frågan tar inte emot svar just nu.**, **Tiden är ute.**, **Ert svar är låst.**, **Svaret passar inte frågan.**, **Fyll i svaret innan ni skickar det.** | |
| Sound blocked by the browser | **Klicka för att slå på ljudet** | |
| The live control's notes and scoring | **Anteckningar**, **Anteckningar för frågan på TV:n**, **Poängsättning: Poängnivåer** / **Närmast vinner**, **Exakt rätt: 3 p**, **Inom ±1: 2 p**, **Plats 1: 3 p**, **Bästa nivån räknas.**, **Lika nära delar plats.**; on the TV an activity is **Aktivitet** | |
| The question's countdown | **Pausa** / **Fortsätt**, **+15 s**; at zero **Tiden är ute!** | Starta om, Tiden är slut |

Messages say what to do, in a full sentence ending with a period: "Lägg till minst 2 alternativ att sortera."
